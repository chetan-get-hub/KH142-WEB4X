# DataCleaning4U Sample Datasets

This directory contains clean and synthetic demo datasets representing the four supported core domains:

1. `sales_sample.csv`: Sales and retail transaction data containing missing values, duplicates, numeric strings, and sales volume outliers.
2. `healthcare_sample.csv`: Patient record sample with clinical metrics, missing test values, and formatting inconsistencies.
3. `hr_sample.csv`: Employee HR metrics dataset with salary figures, performance scores, department categories, and duplicate records.
4. `finance_sample.xlsx`: Multi-sheet Excel workbook with banking/financial data (Transactions and Accounts sheets) to test Excel sheet selection and multi-table capabilities.

*Note: Do not commit real or confidential user data into this directory.*
